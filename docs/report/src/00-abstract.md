# ABSTRACT

Aegis Wealth AI is an AI wealth-advisory agent built for Topic B (Wealth Advisory Agent) of the 2026 Shenzhen International FinTech Competition, International Track, whose theme is "AI as a Financial Participant" [@competition]. It follows the workflow of a licensed advisor. It profiles a client's risk, compares products, proposes an asset allocation and checks it against compliance rules. It explains the result in plain language, executes it in a simulated sandbox account once the client confirms, and keeps a tamper-evident record of every recommendation.

The design rests on one principle: tested code computes every number and enforces every rule, while the language model only asks, talks and explains. The advisor agent works through eleven strict tools behind a permission broker with tiers T0 to T2. No tool can confirm or execute an order, so execution needs the client's own comprehension quiz, Confirm click and a one-time token. Every proposal version passes through a nine-rule compliance gate, and each rule names the regulation it implements. Every figure in an agent reply must match a tool result, or the reply is regenerated and, failing that, replaced by a checked template.

A compliance officer supervises the AI from an AI Control Room. It offers live alerts, a review queue of flagged turns, a model disclosure with configuration fingerprints, and two switches that suspend the advisor or halt execution at once. A monitoring loop moves a simulated market and measures drift from the agreed mix. It proposes rebalancing only through the same gate and the client's own Confirm.

This document describes the system as built: its architecture, its core algorithms and its security design. The build passes 196 backend tests, including the twelve acceptance tests of the project documentation. Of 30 red-team attacks, none placed an order, passed an unsuitable proposal, leaked another client's data or put an unsupported number in a final reply. The deterministic endpoints answer in about 5 ms at the 95th percentile. The system runs with one Docker command, and a live demonstration is hosted at https://aegis-wealth-ai.onrender.com.
